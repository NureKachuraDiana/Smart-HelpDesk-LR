## Перевірка специфікації

За наявності Python 3.10+ в корені репозиторію запустіть:

```bash
python scripts/check_spec.py
```

Очікуваний результат: **FR-01–FR-07: 7/7 = 100%** специфікаційного покриття, 9 REST маршрутів, 3×3 матриця статусів та 15 зв'язків простежуваності. Це **не** тестування працюючого застосунку, а перевірка проєктних матеріалів.

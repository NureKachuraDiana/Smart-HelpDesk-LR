
# Smart HelpDesk — Лабораторна робота №1

## Опис проєкту

Smart HelpDesk — система для автоматизації роботи служби технічної підтримки.

Основні можливості майбутньої системи:

- Створення та перегляд звернень.
- Фільтрація за статусом і пріоритетом.
- Редагування інформації про звернення.
- Призначення відповідальних виконавців.
- Керування статусами звернень.
- Додавання та перегляд коментарів.
- Збереження інформації у SQLite.
- Використання AI для рекомендацій у ЛР4.

## Виконані завдання

У межах лабораторної роботи №1:

1. Проаналізовано вимоги замовника.
2. Визначено функціональні та нефункціональні вимоги.
3. Розроблено User Stories та критерії приймання.
4. Створено модель даних і матрицю переходів статусів.
5. Визначено правила валідації та часткового оновлення.
6. Спроєктовано архітектуру системи.
7. Розроблено контракт REST API.
8. Сформовано матрицю простежуваності вимог.
9. Проведено аналіз специфікації з використанням ChatGPT.
10. Виконано перехресне рев'ю документації.

## Перевірка специфікації

Для автоматизованої перевірки документації використовується Python-скрипт.

Запуск із кореневої папки репозиторію:

```bash
python LR1/scripts/check_spec.py
```

Також налаштовано GitHub Actions для запуску перевірки під час внесення змін.

## Результати

За результатами лабораторної роботи сформовано специфікацію Smart HelpDesk.

Покриття функціональних вимог FR-01–FR-07 критеріями приймання та майбутніми тестами становить 100%.

Розроблена документація є основою для реалізації REST API у ЛР2, тестування у ЛР3 та інтеграції AI-рекомендацій у ЛР4.

## Висновок

У ході лабораторної роботи отримано практичні навички аналізу вимог, використання AI-асистента, проєктування архітектури програмного забезпечення та підготовки технічної документації.

Реалізація програмного сервісу в межах ЛР1 не вимагалася.
